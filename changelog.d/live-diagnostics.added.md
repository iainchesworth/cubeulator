**A diagnostics channel for developers.** While the app runs, Settings > Developer (or Ctrl+Shift+D) can start writing what the scan reads and decides - each side's colours, how they were named, how the cube was put together, what the camera accepted, where the solve stands - to a file at a fixed place for the user, one JSON object per line, for another program or a person to read while the app is still up. A snapshot writes the whole current scan and solve as one record. It is off at every start unless `CUBE_DIAGNOSTICS` says otherwise, writes numbers and names and never a camera frame unless a separate switch is on, and replaces the `CUBE_HELD_LOG` file. See [docs/diagnostics.md](docs/diagnostics.md).
