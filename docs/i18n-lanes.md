# What each lane has to change for translation

Generated by `python tools/i18n/lint_strings.py --report > docs/i18n-lanes.md`
from `tools/i18n/lint_allowlist.json`: every user-visible literal in a file
that is not the experience lane's, by lane, with the id in
`docs/design/strings.json` whose English is the same where there is one. The
lint (`i18n_no_unwrapped_literals`) fails when an entry's text is gone, so
this list can only shrink; whoever converts a literal removes its entry and
regenerates this page. [`i18n.md`](i18n.md) says how.

"No exact id" does **not** mean no id. The design's wording often differs from
what the screen says today; the id to use is the one the screen's spec names
(`design/screens/scan.md`, `solve.md`, ...), not one found by matching
English. A literal that is a fragment (`' OF '`, `'STAGE '`) is one half of a
sentence: the design has it whole, with `%1` for the number.

What a lane does with each row: replace the literal with `qsTrId("<id>")`,
delete the allowlist entry, run `ctest -R i18n`.

Besides the literals:

- **Solve lane.** `solve.rescan` is placed off the left edge of the window in a
  right-to-left language (found by `tests/i18n/system/language_test.cpp`, at
  every window width from 720 up): `SolveScreen.qml` positions it with an x
  that does not follow the layout; use `anchors.left`/`anchors.right`, which
  mirror. Nothing in `Cube3DView.qml` or `HeldCube` has to change for
  right to left: the 3D cube is not affected by layout mirroring, and a test
  (`cube_i18n_screen_tests`) holds the cube and all 18 turns to the solver's
  in a mirrored root. The turn wording is built in QML from fragments
  (`'quarter turn'`, `'half turn'`, ` facing you`): use the 18 whole-sentence
  `turn.*` ids, which are what a screen reader and Review the solution read.
  `SolveController` exposes codes already; it needs no change.
- **Scan lane.** `DirectScan.cameraError` is `cube::to_string(CubeError)`
  (`src/lib/include/cube/error.hpp`): expose the enum's name and word it in QML
  with `scan.camera.*`. `SettingsModel.handDetectionUnavailableReason`: expose
  a code. `ScanSession`'s retry fragments go with it in R6. `AppState.qml`'s
  two messages travel with the scan flow when E2a splits the file.
- **Kit session.** The seam is in `i18n.md`: `Theme.rtl` and the face from
  `LanguageManager`, `SettingsState.language` written through
  `LanguageManager.setLanguage()`.
