## [Unreleased]

### Added

- Tracy profiler instrumentation, the same as the rest of the application
  family: `cube/profiling.hpp` macros (zones, frames, plots, messages) behind
  `CUBEULATOR_ENABLE_TRACY` and an opt-in `profiling` vcpkg feature, with
  `*-profiling` presets. Capture, the vision pass and its pipeline stages,
  both ONNX inferences, the tracker, the Qt Quick frame and every solver stage
  are instrumented; off by default and compiled to nothing. See
  [docs/profiling.md](docs/profiling.md).
- Third-party notices generated by the build (`cmake/ThirdPartyNotices*.cmake`,
  `third_party/notices/`): the shipped components, their licences and texts,
  embedded as `:/licences/*` and installed with every desktop package; a
  CTest case fails when something that ships has no notice. Licence inventory
  and the Qt/App Store options paper in [docs/licensing.md](docs/licensing.md).
- Repository skeleton: folder layout, CMake build system (presets, warnings,
  sanitizers, coverage, packaging), vendored vcpkg submodule, CI/security
  workflows (CodeQL, OSV-Scanner, Zizmor, Scorecard, dependency review),
  mkdocs documentation site, and stub `cube::lib`/`cube::platform`/
  `cube::gpu_render` targets. No solver, computer vision, edge-AI, or
  rendering logic yet — see [Architecture](docs/architecture.md).
